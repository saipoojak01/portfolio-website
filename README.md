# Sai Pooja K – Portfolio

React + Vite + Tailwind CSS + Framer Motion. Static frontend, hosted on Vercel.

## Run locally
npm install
npm run dev

## Edit content
All text, projects, skills and links live in `src/data.js`.
Resume: replace `public/Sai_Pooja_K_Resume.pdf`.
Screenshots: put images in `public/screenshots/` and set `image: '/screenshots/name.png'` for a project in `src/data.js`.

## Deploy on Vercel
1. Push this folder's contents to your GitHub repo (replace the old index.html, sai.jpeg and resume.pdf).
2. On vercel.com choose Add New > Project and import the repo.
3. Vercel detects Vite automatically (build: `npm run build`, output: `dist`). Click Deploy.
